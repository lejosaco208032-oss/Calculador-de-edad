# Calculadora de Edad Dinámica 📅

Una herramienta sencilla y rápida para calcular la edad basada en los últimos 2 dígitos del año de nacimiento.

## Características
- **Cálculo instantáneo:** No requiere botón de calcular.
- **Lógica inteligente:** Detecta automáticamente si el año pertenece al siglo XX o XXI.
- **Siempre actualizado:** Utiliza la fecha del sistema, por lo que funcionará correctamente en 2026, 2027 y años futuros.
- **Diseño Responsive:** Adaptado para móviles y PC.
